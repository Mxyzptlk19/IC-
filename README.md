## Camonitor Post-Processor
The scrip `camonitor_post_processing.py` is meant to format sensor data extracted via camonitor EPICS protocol.

### How to use

1. Create directories `data/` and `data/raw/`. Inside `data/raw/` folder, add files generated by camonitor data gathering;

2. Select file to be processed by asserting its name to variable `RAW_FILE_NAME`;

3. Define signals sources in raw file to be treated as x and y variables in processed file by giving those names in variables `X_VAR` and `Y_VAR`. For now, script only supports one x variables, while being able to take multiple y variables;

4. Make sure to have the correct dependencies installed: `python3+`, `pandas` and `matplotlib`;

5. Execute processing by running command `python camonitor_post_processor.py`.
